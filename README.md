# Excel-Freshco-Hypermart-Orders-Delivery-Analytics

1. Project Overview -
Frescho Hypermart Orders & Delivery Analytics is a comprehensive Excel-based business project created to evaluate supermarket orders, fulfillment metrics, and delivery performance. The workbook provides structured analysis on order timelines, delivery operational bottlenecks, and customer lifetime value (LTV).

2. Business Problem -`
Supermarket operations generate massive transaction datasets across multiple delivery slots, geographic locations, and customer channels, making it complex to track manual efficiency. The objective of this project is to process and analyze raw supermarket records to monitor:
* Order fulfillment and delivery performance.  
* Customer acquisition source effectiveness and LTV.  
* Delivery delays and completion rates across weekdays, slots, and months.
  
3. Goal of the Workbook -
The main goal is to deliver a multi-sheet analytical workbook utilizing advanced Excel functions to enable stakeholders to filter and review:
* Order Level Analysis – Order distribution across delivery areas, slots, and product amounts.
* Complete Rate Analysis – Completion rates across days, time slots, and months.
* Customer Level Analysis – Aggregated LTV and distinct user counts at the acquisition source level (Facebook, Google, Instagram, Organic, etc.).
  
4. Tools & Technologies -
* Microsoft Excel – Advanced formulas, data validation, and text transformation.  
* Pivot Tables & Pivot Charts – Multi-dimensional data aggregation, dynamic summaries, and visual representation.  
* Data Modeling & Cleaning – Structuring transaction records, managing date/time formats, and resolving workbook links.
* File Formats – ⁠.xlsx⁠ workbook containing cleaned transaction datasets and interactive pivot analysis tabs.

5. Data Source -
* Source: SkilloVilla Capstone dataset containing transaction logs for Frescho Hypermart.  
* Datasets Include: Over 22K+ supermarket records detailing order timestamps, delivery zones, pickup/drop geographies, acquisition channels, and completion flags.
  
6. Features / Highlights -
Key Metrics & Findings:
* Dataset Scale: Analyzed 22K+ supermarket orders.  
* Completion Tracking: Highlighted a 99.63% organic completion rate across transaction logs.  
* Delivery Timings: Evaluated weekend delivery timelines reaching 48:30 hours peak durations.  
* Operational Bottlenecks: Identified critical fulfillment bottlenecks and delivery drop areas.
   
7. Key Insights -
The workbook successfully uncovers:
* High-performing customer acquisition sources driving distinct users and product amounts.
* Slot-wise and weekday-wise patterns influencing supermarket order completion rates.
* Delivery time variations across different geographical zones (e.g., Bellandur, HSR Layout, etc.).
